# Стандартный шаблон виджета — прототип

Шаги: 1 — стартовый экран; 2 — окно настроек виджета (шестерёнка); 3 — окна «Размер» и «Стиль»;
4 — компонент «Выбор цвета» и окно выбора цвета (Фон / Заголовок / Маркер): галочка и крестик закрывают окно.
Цвета пока не применяются.

## Запуск

В папке проекта:

    python3 -m http.server 5173

Откройте http://localhost:5173

(или `npx serve .` / `npx vite`, если Node уже стоит)

## Файлы

- `index.html` — разметка и набор SVG-иконок
- `styles.css` — стили и токены цветов из макета
- `app.js` — клики
- `fonts/` — шрифты
